Madeline Clinton's Final Project: LightLeaf!

For my final project in HCDE 439, I decided to build off of previous assignments and create a project that shows users if plants are getting enough light by showing green for good lighting and red for bad lighting. I wanted to do this because I have a lot of plants and I wanted to make a prototype of an easy way to check if they are getting enough light without having to check the lighting in the room. For this project, I used and RGB LED, a photocell, and an Arduino. I also 3D printed a case for the Arduino and a case for the circuit.

Arduino Code

        // Constants that won't change
        const int analogInPin = A0;  // Analog input pin that the potentiometer is attached to
        const int redLED = 9;  // Analog output pin that the red LED is attached to
        const int greenLED = 10; // Analog output pin that the green LED is attached to

        int sensorValue = 0;  // value read from light
        int redOutputValue = 0; // value output to the PWM (analog out) - red LED
        int greenOutputValue = 0;  // value output to the PWM (analog out) - green LED

        void setup() {
        // initialize serial communications at 9600 bps:
        Serial.begin(9600);
        }

        void loop() {
        // read the analog in value:
        sensorValue = analogRead(analogInPin);

        // contrain the sensor values based on light: red for low light and green for higher light
        int sensorValueRed = constrain(sensorValue, 200, 300);
        int sensorValueGreen = constrain(sensorValue, 200, 400);


        // map it to the range of the analog out: 
        redOutputValue = map(sensorValueRed, 300, 200, 0, 255); // red LED will be higher when light is lower
        greenOutputValue = map(sensorValueGreen, 200, 400, 0, 255); // green LED will be higher when light is higher

        // change the analog out value:
        if (sensorValue < 300) { // if the light is low enough, map red LED
          analogWrite(redLED, redOutputValue);
        } else { // if the light is too high, don't turn on red LED
          analogWrite(redLED, 0);
        }

        // if the light is not lower than 700, turn on green LED
        analogWrite(greenLED, greenOutputValue);

        // print the results to the Serial Monitor:
        Serial.print("light sensor = ");
        Serial.print(sensorValue);
        Serial.print("\t RED output = ");
        Serial.println(redOutputValue);
        Serial.print("/t GREEN output = ");
        Serial.println(greenOutputValue);

        // wait 2 milliseconds before the next loop
        delay(2);
        }

Technical Write-Up

For this project, I started with an idea of what I wanted to create. I then assessed what would be a realistic and achievable project I could make that would be a prototype of my idea. Using the matierals listsed above, I first practiced this project in assignment 3. I then built off of them to use a RGB LED and a mini breadboard to make the circuit more compact. I first built my circuit on a full sized breadboard the way that I was used to. I then assesed what I would have room for and what I would need to adjust so that it fit on the mini breadboard. I also had to strateigically place the LED and photocell so that they could be enclosed and not have the light from the LED interfere with the photocell. I then had to calculate the resistor values for the RGB LED and make a schematic to make sure I was connecting everything correctly. The most tedious part of this project was mapping the sensor values to the output values for the LEDs. The photocell is very sensitive, so I had to do a lot of testing and adjusting to get the right ranges for the sensor values and the output values. I also had to adjust the code so that the red LED would only turn on when the light was low enough and the green LED would only turn on when the light was high enough. The weather in Seattle has been sunny for 30 minutes or very gloomy lately so the light levels have been different each time I tested my project. Overall, I am really happy with how this project turned out and I think it is a good prototype for the idea I had. If I were to continue working on this project, I would like to expand the RGB LED to a whole strip of RGB LEDS that could wrap around the plant's pot. This way, it will be more visible and visually appealing because I could hide the circuit somewhere else. I would also want to have specific lighting settings based on the plant. So the photocell will be more sensistive for full light plants and less sensistive for low light plants.
